# Guía Técnica: Desarrollo web corporativo con HTML5 y CSS3

Documentación técnica elaborada para explicar cómo las empresas modernas diseñan, estructuran y optimizan sus portales web mediante estándares abiertos (**HTML5** y **CSS3**), así como el flujo de trabajo documental implementado con **MkDocs** y **GitHub Pages**.

## En esta documentación encontrarás, entre otros: 

* **Uso empresarial de HTML y CSS:** Cómo las compañías pasan de webs estáticsa rígidas a sitios semánticos, accesibles y adaptables a móviles. También se llama *Responsive Design*.
* **Ejemplos de código listos para producción:** 
* `mkdocs build` - Build the documentation site.
* `mkdocs -h` - Print help message and exit.
